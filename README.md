# utils

A collection of `Mathematica` tools I often use in research code.

- `utils.m` a general-purpose utility belt. Inspired by
  [alibrary](https://github.com/magv/alibrary)
- `exterior.m` basic exterior algebra functionality
- `cmats.m` companion matrix constructions
- `fftensor.m` tensor tools for
  [FiniteFlow](https://github.com/peraro/finiteflow)

These tools are for personal use and will probably evolve over time.
Documentation will be added one day.
